# MKII - Assembly
Project made in RISC-V Assembly as a demonstration of low-level programming and optimizations.

## How to play:
1. Run the "Rars14_Custom4.jar" application
2. Check if "Settings > Initialize Program Counter to global main if defined" is active
3. Open the file "jogo.s" in the editor
4. Open the "Tools > Bitmap Display" window and connect to the program
5. Open the "Tools > Keyboard and Display MMIO" Simulator window and connect to the program
6. Press Assemble and run the application
7. Make sure that the inputs are sent through the Keyboard field.

Have fun!

## Menu Commands: 
- W, A, S, D: Move
- ENTER: Confirm

## In-Game Commands: 
- A, D: Move
- Q, W, E: Jump vertically or diagonally
- J: Punch
- K: Kick
- L: Guard
